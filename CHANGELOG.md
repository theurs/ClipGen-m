# Changelog

Все значимые изменения проекта ClipGen-m.

## 0.31

### Добавлено
- **Новый LLM-бэкенд `cmd/openailike`** — утилита для любого OpenAI-совместимого API
  (OpenAI, Ollama, LM Studio, vLLM, OpenRouter, Together, Groq, LiteLLM, свой прокси).
  - Адрес API настраивается в `openai.conf` (`base_url`) или флагом `--base-url`.
  - Авто-обнаружение моделей через `GET /v1/models`, если модели не заданы в конфиге.
  - Локальные серверы работают без ключа (заголовок `Authorization` не отправляется).
  - Флаги `--model` и `--list-models`; единые флаги остальных утилит поддерживаются полностью.
  - Мультимодальность: изображения (`image_url`), текстовые файлы, аудио (`/v1/audio/transcriptions`).
  - Общая история чатов в `%APPDATA%\clipgen-m\llm_chats\` — совместима с Gemini и Groq.
- Пункты трея «OpenAI Config» (`openai.conf`) и «OpenAI Log» (`openai_err.log`).
- Сборка `openailike.exe` в `release.bat`.

## 0.30

### Удалено
- **Графический чат ChatUI** (`cmd/chatui`): отдельный Go-модуль, пакеты `internal/chat`,
  `internal/config`, `internal/llm`, `internal/ui`, иконки, манифест и документация.
- Из основного приложения убраны: хоткей чата (`Ctrl+M`), запуск/закрытие окна чата,
  ключи `chatui_path` и `chatui_hotkey` в конфиге, а также вспомогательный WinAPI-код
  (`EnumWindows`, `GetWindowThreadProcessId`, `SendMessageTimeoutW`).
- Из `release.bat` убран блок сборки ChatUI.

## 0.29

### Исправлено
- **Переключение раскладки (`layout_switch`)** перестало подвисать:
  - отключён бэкап буфера обмена (он создавал блокировки) — теперь он нужен только для ИИ-действий;
  - таймаут копирования выделения сокращён с 1 с до 100 мс, шаг проверки — 10 мс;
  - искусственные паузы 150/200/400 мс заменены микропаузами 20 мс.
- **Алгоритм переключения переписан на пословный**: слова конвертируются независимо
  (кириллица ↔ латиница), пробелы и знаки препинания сохраняются как есть.
  Раньше для всего текста выбиралось одно направление по большинству букв, из-за чего
  второй язык игнорировался, а пунктуация портилась.

### Удалено
- **Mistral LLM** (`cmd/mistral`) и **GitHub LLM** (`cmd/ghllm`).
- Пункты трея «Mistral/GitHub Config» и «Mistral/GitHub Log».
- Провайдер `mistral` из ChatUI, ключ `mistral_args` переименован в `llm_args`
  (старый ключ продолжает работать).
- Каталог истории чатов `mistral_chats` переименован в `llm_chats` — старый каталог
  используется автоматически, пока новый не создан, поэтому история не теряется.
- Дочищен «хвост» прошлого удаления — `cmd/cerebrasllm` (пакет без `main`, из-за которого
  не собирался весь модуль).
- Вспомогательные утилиты вынесены из-под `cmd/mistral`: `cmd/lua-executor`
  (используется geminillm как калькулятор) и `cmd/tavily-test`.
